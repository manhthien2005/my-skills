# Visual Director

Choose visual treatment based on audience and content. Themes in `configs/themes/`:
- `editorial-cream`: warm editorial, serif display and coral accent; research/thesis narrative.
- `keynote-night`: dark visual emphasis, modern sans typography; product/technology keynote.
- `swiss-contrast`: high-contrast grid and red accent; formal executive and corporate talks.

## Layout routing

- Thesis or headline → `statement`, `cover`, `section`.
- 2–4 important facts → `metrics` (short labels, explicit sources).
- An ordered real workflow → `process` (up to six steps); chronological change → `timeline`.
- Two distinct alternatives → `comparison`.
- Quantitative pattern → `chart` (zero-based bars, direct labels, no fake precision).
- Concept categories → `columns` (at most four); decision/conclusion → `summary`.
- Direct verbatim sourced statement → `quote` (must verify wording and source).
- Permission-cleared visual → `image-split` (local asset and attribution).

Create **three style previews** only when the user requests a choice or the style is unsettled. Do not change a user-approved aesthetic by default. Limit repeated layouts and use meaningful contrast between opening, argument, data and closing pages.

## Anti-patterns

Avoid text-wall slides, decorative charts without insight, heavy border cards everywhere, overly long titles, inconsistent icons, unsupported stock photos, illegible footnotes, and color-as-the-only encoding. Body typography should remain readable at presentation distance. Render before asserting design quality.
