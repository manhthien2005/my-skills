# Provenance, architecture inspiration & licensing

- **Aphrodite-slide** Python/HTML/CSS renderer, design-system presets, docs, examples and checks derive from original Personal Slide Studio V1 authored in this chat; released under bundled MIT for this new package only.
- **Slide Kit provided by user:** `slide-kit.zip` had a legacy `html-slide-deck` SKILL.md, 12 standalone HTML layout templates and 5 Python tools. The archive had no license in its contents. Its original code/templates are **NOT** bundled with the GitHub-ready edition. Copying them into a publicly readable repository requires independent redistribution rights. Main JSON renderer works without them.
- **Methods studied (not vendored/copy-pasted):** [Frontend Slides](https://github.com/zarazhangrui/frontend-slides), [Slide Skill](https://github.com/hunkim/slide-skill), [Slides Skill](https://github.com/Rich627/slides-skill), [Anthropic Skills/PPTX](https://github.com/anthropics/skills). These repos have different terms and may change; do not assume uniform licensing, clone/install/execute code without a specific review, or imply these are bundled here.
- **Optional dependencies:** `playwright`, `pillow`, `python-pptx` with their respective licenses and packaging requirements; no paid LLM/image API required by the code in this package.

Do not use images scraped from the internet without checking attribution, license and consent. Example deck is simulated, not a verified company case.
